# Personal Portfolio

A modern, responsive full-stack portfolio application designed to showcase projects, skills, and professional experience, featuring an integrated contact system with real-time email notifications.

---

## Technologies Used

- **React 19 & JavaScript (ES6+):** Frontend library for building a dynamic, component-driven user interface.
- **Vite:** Next-generation build tool providing fast development and optimized production builds.
- **React Router DOM:** Client-side routing for seamless Single Page Application (SPA) navigation.
- **Tailwind CSS & PostCSS:** Utility-first framework for responsive styling and custom UI design.
- **Framer Motion:** Smooth page animations and interactive micro-transitions.
- **Axios:** Promise-based HTTP client for API requests between client and server.
- **React Hook Form & Zod:** Form management and schema validation for the contact module.
- **Sonner:** Toast notifications for real-time user feedback.
- **Vercel Analytics:** Web performance and visitor analytics tracking.
- **React Icons:** Icon library integration for visual UI components.
- **Node.js & Express.js 5:** RESTful API backend managing server logic and contact endpoints.
- **Resend API:** Cloud email service integration for instant message dispatch.
- **CORS & Dotenv:** Cross-origin request handling and environment variable management.

---

## Key Features

- Fully responsive layout optimized for mobile, tablet, and desktop devices.
- Interactive sections showcasing Projects, Professional Experience, Skills, and About Me.
- Contact form with client/server validation, toast alerts, and automated email delivery.
- Modular client-server architecture with SPA routing.
